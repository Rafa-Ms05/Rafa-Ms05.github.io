Distributed Messaging Platform

Sistemas Distribuídos

Sistema de mensagens tipo email, com arquitetura distribuída composta por múltiplos serviços (utilizadores, mensagens, gateway) expostos via REST e gRPC. Comunicação segura entre servidores com TLS, mensagens processadas com Kafka, persistência via Hibernate, e replicação para tolerância a falhas. Inclui integração com um provedor de email real (Zoho) e containerização com Docker.

  • gRPC
  • Protobuf
  • Kafka
  • Hibernate
  • TLS
  • Docker

TrainSystem — Estruturas de Dados

Algoritmos & Estruturas de Dados

Implementação de estruturas de dados próprias — pilhas, filas, listas, dicionários, tabelas de hash e árvores AVL — construídas desde a base, sem recorrer às coleções nativas do Java.
